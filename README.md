# Personal GitHub Pages Site

This is a static website starter for GitHub Pages.

## Pages
- Home
- About
- Projects
- Home Lab
- Certifications
- Links
- Contact

## Publish with GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files in this folder to the repository.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Set the source to **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Save.
8. Your site will be available at `https://YOURUSERNAME.github.io`.

## Before Publishing
Search the files for:
- `Your Name`
- `your-public-email@example.com`
- `href="#"`
- `YOURUSERNAME`

Replace those placeholders with your real public information.

## Important
Do not publish passwords, API keys, tokens, private IP plans you consider sensitive, VPN keys, internal-only credentials, or anything you would not want publicly visible.
